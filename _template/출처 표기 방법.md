블로그 글을 작성할 때의 출처 표기는 논문이나 보고서처럼 엄격한 형식을 맞추기보다, 가독성과 저작권 보호를 목적으로 쉽고 명확하게 작성하는 것이 중요합니다.
가장 핵심은 원작자에 대한 예의를 갖추고, 독자가 원본을 쉽게 찾아갈 수 있도록 링크를 연결하는 것입니다.

## 1. 블로그 출처 표기의 3대 원칙

• 텍스트 형태: `[출처] 저자/사이트명, 「글 제목」` 구조로 글의 맨 아래나 인용한 문단 바로 밑에 적습니다.
• 하이퍼링크 연결: 출처 명칭에 원본 주소(URL) 링크를 걸어 독자가 바로 이동할 수 있게 합니다.
• 이미지 출처: 외부 이미지를 사용할 경우, 이미지 바로 아래에 작게 출처를 밝힙니다. (예: `출처: 픽사베이, 출처: OO님 블로그`)

## 2. 상황별 출처 표기 예시

### 2.1. 다른 블로그나 웹사이트 글을 인용할 때

글의 하단이나 인용구 바로 아래에 표기합니다.

```
• 예시 1: [출처] 네이버 지식백과 「인공지능의 역사」 (링크 삽입)
• 예시 2: (출처: 홍길동님 블로그 'IT 트렌드 분석' 글 참고)
```

### 2.2. 뉴스 기사를 인용할 때

기사 제목과 언론사명을 명시하고 링크를 겁니다.

```
• 예시: [출처] 한국경제, 「2026년 하반기 경제 전망」 기사 (링크 삽입)
```

### 2.3. 책(단행본) 내용을 인용할 때

책 제목과 저자, 필요하다면 페이지까지 적어주면 신뢰도가 높아집니다.

```
• 예시: [출처] 저자 홍길동, 『블로그 글쓰기의 모든 것』, OOO출판사, p.45
```

## 3. 알아두면 좋은 블로그 작성 팁

• 네이버 블로그 '인용구' 컴포넌트 활용: 네이버 블로그 스마트에디터의 인용구(따옴표 모양) 기능을 사용해 인용 단락을 시각적으로 분리하면 글이 훨씬 깔끔해집니다.
• 무단 불펌 주의: 출처를 밝히더라도 원작자가 '무단 전재 금지'를 명시했다면 글 전체를 그대로 긁어오는 것은 저작권 침해가 될 수 있습니다. 핵심 요약 후 본인의 생각을 덧붙이는 방식을 권장합니다.
• 무료 이미지 사이트 이용: 상업적 이용이 가능한 Pixabay, Unsplash 등에서 이미지를 가져왔다면 `출처: Pixabay` 형태로 매너 있게 표기해 주는 것이 좋습니다.
