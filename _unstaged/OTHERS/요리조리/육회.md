# 냉동 우둔살로 가성비 육회 만들기

출처: [유튜브: 육회 - 식품의 비밀 서울사는 곰](https://youtu.be/CJ-KS-Kinn0?si=BbzGmgbaWhFwhXbt)

## 1. 고기 선택

* 추천 부위: **우둔살**
* 비교 부위: 설도
* 우둔살이 설도보다 약 1,500원 비싸지만 육향이 더 풍부하다.
* 나이스미트 업소용 육회 1kg

## 2. 해동 방법

냉동육의 서걱거리는 식감이 싫다면 다음과 같이 해동한다.

1. 먹을 만큼 약 250g을 덜어낸다.
2. 해동지 또는 키친타월 위에 고기를 넓게 펼친다.
3. 랩을 씌운다.
4. 냉장고에서 천천히 해동한다.
5. 적당히 녹으면 바로 양념한다.

상온이나 물에 담가 해동하지 않고, **냉장 상태에서 해동하는 것**이 핵심이다.

## 3. 레시피

### 재료

* 육회용 냉동 우둔살 250g
- 맛소금 1 작은술
- 설탕 3 큰술
- 연두 3 큰술
- 참기름 5 큰술
- 고추기름 5 큰술
- 깨소금 3 큰술
- 다진마늘

### 추가 구성

- 달걀노른자
- 깨
- 채 썬 배
- 치즈

### 만드는 방법

1. 냉장 해동한 고기의 핏물과 수분을 가볍게 제거한다.
2. 맛소금, 설탕, 다진 마늘, 참기름을 넣는다.
3. 양념이 고기 표면에 고르게 묻을 정도로 빠르게 버무린다.
4. 간을 확인한 뒤 바로 먹는다.

* 맛소금: 조금씩 넣으면서 간 조절
* 설탕과 다진 마늘: 비교적 넉넉하게 사용
* 양념 후 오래 두지 말고 바로 섭취

## 4. 식품 안전 주의사항

육회는 가열하지 않기 때문에 일반적인 구이·볶음용 고기보다 위생 관리가 중요하다.

* 반드시 신뢰할 수 있는 판매처의 **육회용·생식용 쇠고기**를 사용한다.
* 배송 중 냉동 상태가 유지됐는지 확인한다.
* 냉장고에서 필요한 양만 해동한다.
* 한 번 해동한 고기는 다시 냉동하지 않는다.
* 칼, 도마, 그릇과 손을 깨끗하게 관리한다.
* 해동 후에는 가능한 한 바로 조리하고 섭취한다.
* 냄새나 색, 표면 상태가 평소와 다르면 생으로 먹지 않는다.
* 임산부, 영유아, 고령자 및 면역력이 약한 사람은 생고기 섭취를 피하는 것이 안전하다.
