# Dreamhack - Recover 문제 풀이

## 1. Intro

문제 링크: <https://dreamhack.io/wargame/challenges/1569>

> 본 문제에서는 _chall_ 바이너리와 _encrypted_ 파일이 제공됩니다.
> _chall_ 바이너리는 플래그가 담긴 _flag.png_ 파일을 정해진 방식으로 암호화하여 _encrypted_ 파일로 저장합니다.
> _flag.png_ 파일을 복구하여 플래그를 획득하세요.
> 플래그 형식은 DH{...} 입니다.

## 3. 암호화 함수 분석

현재 작업 디렉터리의 `flag.png`를 암호화하여 `encrypted`로 저장한다.

1. `flag.png`를 `rb` 모드로 연다.
2. `encrypted`를 `wb` 모드로 연다.
3. 입력을 1바이트씩 읽는다.
4. 4바이트 키를 순환하며 XOR한 뒤 0x13(19)을 더한다.
	암호화 식: `C[i] = ((P[i] XOR K[i % 4]) + 0x13) & 0xff`
5. 결과의 하위 8비트를 1바이트로 기록한다.
6. EOF에서 두 파일을 닫고 종료한다.

파일 열기에 실패하면 `fopen() error`를 출력하고 종료 코드 1로 끝난다.

**메모리에서 실제 키 확인**

Decompile 창의 `DAT_00102004`를 더블클릭해 `00102004`**로 이동했다. 해당 주소부터 바이트를 읽으면 다음 값이 있다.

![500x256](https://cdn.jsdelivr.net/gh/s3mper/s3mper.github.io@main/_image/2026-10-15-17-40-08.png)

   앞서 확인한 `% 4` 때문에 접근하는 위치는 처음 네 바이트뿐이다. 따라서 키는 **`DE AD BE EF`**이고, 뒤의 `00`은 사용하지 않는다.

## 복원 

복호화는 더하기를 먼저 되돌리고 XOR을 적용한다:
`P[i] = ((C[i] - 0x13) & 0xff) XOR K[i % 4]`

여기에서 `& 0xFF`는 **계산 결과의 하위 8비트만 남겨, 1바이트 범위인 `0~255`로 맞추는 연산**이다. 원본 C 코드는 결과를 `byte`에 저장하므로, 범위를 넘으면 하위 8비트만 남지만 Python의 정수는 자동으로 1바이트로 제한되지 않으므로 이 동작을 직접 구현해야 한다.

<details>
<summary>코드 접기/펼치기</summary>
<div markdown="1">

```python
from pathlib import Path

key = bytes.fromhex("DE AD BE EF")
data = Path("encrypted").read_bytes()

decoded = bytes(
    ((b - 0x13) & 0xFF) ^ key[i % 4]
    for i, b in enumerate(data)
)

Path("flag.png").write_bytes(decoded)
```
